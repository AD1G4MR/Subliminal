Subliminal
A first-person horror experience built around liminal spaces, atmospheric storytelling, and environmental exploration. Developed in Unreal Engine 5.7, Subliminal expands on an earlier university project, Descent, with a redesigned experience, two new levels, and multiplayer functionality using Unreal Engine's Steam Online Subsystem.
About the Project
Subliminal explores the unsettling feeling of being somewhere that is familiar, but not quite right. The experience uses environmental design, scale, repetition, and carefully composed empty spaces to create tension and isolation through the spaces players move through.

The project is designed to be enjoyed both solo and cooperatively. Its development provided an opportunity to build on the original Descent concept while developing practical skills in level design and online networking.
Key Features
- First-person horror: Explore atmospheric environments built around liminal spaces and environmental storytelling.
- Redesigned experience: Builds on the original university project, Descent, with a reworked structure and two new levels.
- Lobby hub: A waiting-room/reception-inspired environment that establishes the atmosphere and connects players to the themed levels.
- Environmental storytelling: Doorways, visual cues, scale, repetition, and spatial composition help communicate the identity of each location and guide players through the experience.
- Solo and cooperative play: Multiplayer functionality allows the experience to be played alone or with others.
- Steam networking: Multiplayer functionality is implemented using Unreal Engine's Steam Online Subsystem.
Level Design and Atmosphere
The lobby is a central environment in Subliminal. Designed to resemble a familiar waiting room or reception area, it uses scale, repetition, and empty spaces to create an uneasy atmosphere. The setting is recognisable, yet its presentation encourages players to question where they are and why the space feels so unsettling.

Each doorway acts as a gateway to a themed level. Environmental details and visual cues help guide players naturally through the experience while giving each location its own identity.
Technology
- Engine: Unreal Engine 5.7
- Networking: Unreal Engine Online Subsystem – Steam
- Project type: First-person horror / exploration
Opening the Project
1. Download or clone this repository.
2. Make sure Unreal Engine 5.7 is installed.
3. Open Subliminal_V1.uproject with Unreal Engine.
4. Allow the editor to initialise the project and any required files before exploring the content.
Multiplayer functionality uses the Steam Online Subsystem and may require the appropriate Steam and local project configuration to test online sessions. The project is provided as a reference and is not presented as a ready-to-deploy commercial release.
